# Agent instructions

This is the clean public source of Environment Memory.

- Read README.md and the relevant file in docs/ before editing.
- Keep application text and public documentation in English.
- Never commit personal photos, captures, provider responses, budgets, credentials,
  runtime databases or local experiment logs. Do not restore deleted private assets.
- Simulation truth, observed evidence and identity hypotheses are separate.
  Never give simulator object IDs or hidden scene state to a perception model.
- Preserve dated observations, uncertainty and reversible corrections.
- Do not make paid calls, upload or publish without the user's authorization.
- Keep credentials server-side; previews and tests must be offline by default.
- Validate changes with npm run check. Live accuracy requires separate evidence.
- This snapshot intentionally excludes development graph/history and recorded
  experiment fixtures. Do not import them to satisfy a failing test.
